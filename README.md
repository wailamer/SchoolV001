# SchoolV001 - نظام إدارة مدرسة (ASP.NET Core MVC + XML)

نسخة أولية احترافية من نظام إدارة مدرسة مبنية وفق فصل واضح بين:

1. تسجيل الطالب الأساسي (`students.xml`)
2. السجل السنوي (`student-records.xml`)
3. العمليات الأكاديمية المرتبطة بالسجل (الدوام، العلامات، الجلاء)

## التشغيل

يتطلب .NET SDK 8.0:

```bash
dotnet restore
dotnet run --project SchoolV001/SchoolV001.csproj
```

## أبرز ما تم بناؤه

- CRUD أولي للطلاب مع توليد تسلسلي للمعرف والرقم العام.
- إنشاء سجل سنوي أول تلقائي عند تسجيل الطالب.
- إدخال علامات فصل مع حساب تلقائي للمجموع والتقدير.
- تسجيل دوام سريع وحفظه داخل `attendance.xml`.
- تقرير جلاء للحلقة الأولى يجمع بيانات الطالب والسجل والعلامات.
- طبقة تخزين XML آمنة تعيد إنشاء مستند فارغ عند فساد الملف بدل انهيار التطبيق.

## بنية المشروع

- `Controllers/` واجهات النظام الأساسية.
- `Models/Domain/` نماذج المجال.
- `Models/ViewModels/` نماذج العرض.
- `Repositories/` القراءة/الكتابة على XML.
- `Services/` خدمات الأعمال (التسلسل، الترفيع، حساب العلامات، التخزين).
- `Data/` مستودع ملفات XML أثناء التشغيل.
