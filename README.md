# SchoolV001 - نظام إدارة مدرسة (ASP.NET Core MVC + XML)

واجهة عربية RTL لإدارة الطلاب والسجلات السنوية والعلامات وإصدار:
- جلاء الحلقة الأولى.
- كشف درجات الفصل الأول للصفوف الأعلى.

## الميزات الحالية
- إدارة تسجيل الطلاب مع توليد `StudentId` و`GeneralRegisterNumber` و`StudentRecordId`.
- حفظ هوية الطالب في `students.xml` والسجل السنوي في `student-records.xml`.
- إدخال علامات فصلية تفصيلية (أنشطة، شفهي، وظائف، امتحان) وحساب المجموع والتقدير.
- توليد تقرير جلاء الحلقة الأولى وتقرير كشف درجات الفصل الأول.
- بنية XML آمنة: عند تلف ملف XML يتم إنشاء وثيقة فارغة تلقائياً بدل الانهيار.

## التشغيل المحلي
> يتطلب .NET SDK 8.0

```bash
dotnet restore
dotnet run
```

## جاهز للتحميل
يمكن تنزيل المشروع مباشرة كملف ZIP من المستودع أو عبر:

```bash
git archive --format zip --output SchoolV001.zip HEAD
```

## خارطة توسع لاحقة
- إضافة الغياب اليومي والتقارير الصفية.
