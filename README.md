# SchoolV001 - نظام إدارة مدرسة ASP.NET Core MVC

نسخة أولية متكاملة مبنية بهيكل مؤسسي يطابق الدراسة التحليلية:

- **هوية طالب ثابتة** في `students.xml`
- **سجل سنوي مستقل** في `student-records.xml`
- **عمليات أكاديمية مرتبطة بالسجل السنوي**: غياب + علامات + جلاء

## الوحدات المنفذة

- لوحة التحكم
- إدارة الطلاب + توليد أرقام تسلسلية
- إدارة السجل السنوي وربطه بالطالب
- لوحة غياب يومية
- إدخال علامات فصلية تفصيلية
- جلاء الحلقة الأولى مع محصلة ونسبة
- عرض المواد والمعلمين والصفوف والشعب
- إعدادات المدرسة

## التخزين

كل البيانات تحفظ في مجلد `DataXml` مع تحمّل فساد XML عبر `XmlStorageHelper` (fallback لوثيقة فارغة).

## ملاحظات تشغيل

1. يتطلب .NET 8 SDK.
2. شغّل:
   - `dotnet restore`
   - `dotnet run`
